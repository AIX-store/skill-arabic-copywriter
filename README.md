# arabic-copywriter

An AI skill that writes native Arabic marketing and product copy from a brief. It picks a
register (Modern Standard Arabic, light Gulf, or Egyptian), keeps tone and address form
consistent, and handles numerals, punctuation and Latin brand names in right-to-left text.
Every line comes with a back-translation and a character count.

## Install

Claude Code:

    git clone https://github.com/AIX-store/skill-arabic-copywriter ~/.claude/skills/arabic-copywriter

Other agents (Codex, Cursor, Claude Desktop, claude.ai): copy `SKILL.md` into the agent's
instructions or project knowledge.

## Example prompts

- "Write the Arabic hero section for our invoicing app landing page, MSA, friendly tone."
- "This Arabic push notification sounds translated. Rewrite it in a light Gulf register."
- "Give me three Arabic app store subtitles under 30 characters for a fitness app."
- "Turn this English onboarding flow into natural Egyptian Arabic."
